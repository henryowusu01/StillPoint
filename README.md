# StillPoint

A calming mental health tracking web application focused on simplicity,
privacy, and emotional clarity.

## Features
- Clean, calming UI inspired by modern wellness apps
- Smooth entrance animations for reduced cognitive load
- Responsive layout designed from 1366x768 as a baseline
- Authentication UI (UI-only, backend planned)

## Tech Stack
- HTML
- CSS (Flexbox, responsive design)
- JavaScript (DOM manipulation, animations)

## Status
UI foundation complete. Backend and tracking features in progress.
